# Budget Buddy 💰

A simple **C-based personal finance management system** designed to help users manage and organize their financial transactions using fundamental data structures.

## 📌 About the Project

Budget Buddy is a console-based application developed in C as a Data Structures and Algorithms project. It demonstrates how linked lists can be used to store and manage transaction records dynamically.

The project focuses on keeping financial record management simple while applying core C programming concepts and basic data structures.

## ✨ Features

- **Transaction Management:** Maintain records of financial transactions.
- **Linked List:** Store transaction records dynamically using a linked list.
- **Transaction Search:** Search for a transaction using its unique ID.
- **Sorting:** Organize transaction records using sorting operations.
- **Input Validation:** Handle invalid user input.
- **Console Interface:** Interact with the application through a simple terminal-based menu.

## 🛠️ Technologies Used

- **Programming Language:** C
- **Data Structure:** Singly Linked List
- **Compiler:** GCC
- **Development Environment:** Visual Studio Code

## ⚙️ Getting Started

### Prerequisites

Install a C compiler, such as GCC, and ensure it is available in your system's PATH.

### 1. Clone the Repository

```bash
git clone https://github.com/Dev6174/Budget-Buddy.git
```

### 2. Navigate to the Project Directory

```bash
cd Budget-Buddy
```

### 3. Compile the Program

```bash
gcc main.c -o budget-buddy
```

### 4. Run the Application

On Windows:

```powershell
.\budget-buddy.exe
```

On Linux or macOS:

```bash
./budget-buddy
```
